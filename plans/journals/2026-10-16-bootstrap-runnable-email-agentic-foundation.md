# Bootstrap runnable Email Agentic foundation

## What happened

Created a fresh Python 3.12 package with health API, offline configuration diagnostics and explicit gateway smoke command. Locked dependencies, configured local gates and CI, and defined optional PostgreSQL, Neo4j and LGTM services. Documented the full product requirements, six Tool Registry gates, conventions, evidence-driven development and the first read-only Gmail research slice.

## Verification and decisions

The aggregate quality gate passed: Ruff, format, strict Pyright, 29 tests, source distribution and wheel. Compose syntax and interpolation validation passed. A real local HTTP process returned 200 from the health endpoint and was stopped. Independent review found a Compose interpolation prerequisite error in onboarding; the guide now requires database passwords before every real-config Compose invocation.

Gateway contract tests are isolated tests, not proof of external provider compatibility. Container execution, live Google integrations, web search and business workflows remain unverified. No private reference files, credential values or inbox data are included.
